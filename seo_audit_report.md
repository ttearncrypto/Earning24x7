## Fixes Applied in This Commit

### 1. CRITICAL — JSON-LD `jsonify` escaping ✅ FIXED

**Before:** `default.html` used `| escape` and raw Liquid interpolation inside JSON-LD `<script>` blocks, producing HTML entities (`&amp;`) invalid in JSON and unescaped quote characters.

**After:** All structured data values use `| jsonify`:
- `"headline": {{ page.title | jsonify }}`
- `"image": {{ page.image | default: '...' | absolute_url | jsonify }}`
- `"datePublished": {{ page.date | date_to_xmlschema | jsonify }}`
- `"mainEntityOfPage": {{ page.url | absolute_url | jsonify }}`

### 2. HIGH — Duplicate Open Graph / Twitter tags ✅ FIXED

**Before:** Manual `<meta property="og:*">` and `<meta name="twitter:*">` tags duplicated what `{% seo %}` already emitted.

**After:** All manual OG/Twitter tags removed. `{% seo %}` (jekyll-seo-tag) is the single source of truth, reading from `site.logo`, `site.social`, and page front matter.

### 3. HIGH — OG image 512×512 → 1200×630 ✅ FIXED

**Before:** `f9xr.webp` (512×512) used as `og:image`, `twitter:image`, and publisher logo on every page (declared as 1200×630 in schema — false dimensions).

**After:**
- New `assets/authors/og-brand.webp` (1200×630) generated via `tools/generate-featured-image.mjs`
- All page `image:` front matter updated to `og-brand.webp`
- `_config.yml` `image:` and `logo:` set to `og-brand.webp`
- Schema `ImageObject` blocks declare correct 1200×630 dimensions

### 4. HIGH — `dateModified` added ✅ FIXED

Added `dateModified: 2026-09-01` to `_posts/2026-09-01-welcome-to-earning24x7.md` front matter. Layout already supports conditional rendering.

### 5. MEDIUM — Dead `titles_from_headings` config ✅ FIXED

Removed `titles_from_headings:` block from `_config.yml` — plugin was not in `plugins:` list and config was inert.

### 6. MEDIUM — Orphan `_includes/head.html` ✅ FIXED

Deleted `_includes/head.html` (not referenced anywhere; layout defines its own `<head>`).

### 7. MEDIUM — `archive.md` wrong layout ✅ FIXED

**Before:** `layout: page` — fell back to minima theme's `page` layout (inconsistent header/footer vs custom `default.html`).

**After:** `layout: default` — consistent navigation and footer across all pages.

### 8. MEDIUM — Dead `meta keywords` and duplicate meta description ✅ FIXED

Removed redundant `<meta name="keywords">` (ignored by Google since 2009) and removed duplicate `<meta name="description">` (already emitted by `{% seo %}`).

### 9. MEDIUM — Page defaults `theme: minima` ✅ FIXED

Removed meaningless `theme: minima` from `_config.yml` defaults (theme is a site-level config, not a page value).

### 10. LOW — Missing `google-analytics.html` include ✅ FIXED

Created `_includes/google-analytics.html` with GA4 snippet (reads `site.google_analytics` config; only loads in production when ID is set).

### 11. LOW — Inert page-level `image:` in defaults ✅ FIXED

Config defaults now set `image: /assets/authors/og-brand.webp` for all pages, ensuring fallback og:image for pages without explicit front matter.
